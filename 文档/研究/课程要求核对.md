## 2. VC-R-03 题面核对

来源：C 第三节题目 `VC-R-03　退货对账与差异处理系统（挑战档）`，P122–P142。

- 场景（P124–P126）：财务与仓库人工比对两份表格，需发现差异、派人处理、跟踪关闭；面向财务与仓库主管。
- 核心实体（P128）：正向单、取消单、差异单（类型、责任人、状态、处理记录）、角色。
- 必做主链路（P130）：导入两边数据 → 自动比对 → 生成差异单 → 派单 → 处理 → 关闭。

| 规则 | 题面原意 | 源定位 |
| --- | --- | --- |
| R1 | 导入的行数 + 被规则排除的行数 = 原始文件总行数；界面可当场验算，漏算/重复算都应暴露 | C P132 |
| R2 | 差异单不能跳状态：待处理 → 处理中 → 已关闭；关闭必须填处理说明 | C P133 |
| R3 | 同一笔差异不允许重复派单，重复派单拒绝并显示当前责任人 | C P134 |

- 建议非功能指标（C P136）：1 万行订单对账端到端不超过 5 秒，且导入行数可在界面验算。这是题面建议、**尚未测量**，后续规格需定义硬件、计时起止、冷/热启动、数据范围与重复次数，不能以示例性能冒充实测。
- 明确不做起点（C P138–P139）：不做自动调账；不做历史归档。
- 关键数据边界（C P142）：**取消单是独立的新单号，不指向原订单号**。配对规则需自行定义并说明局限；导入行数对账与状态机各要有用例。
- 本轮只取得唯一官方流水，未制造两份“财务事实/仓库事实”。后续必须说明两边输入或视图的来源、观测含义及取消配对歧义，不能把同一流水伪装成独立的真实两账来源。
